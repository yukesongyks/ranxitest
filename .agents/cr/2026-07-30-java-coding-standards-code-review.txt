              阿里巴巴嵩山版 + JDK21」的元信息行。

  [P2] 2. HashMap 初始容量公式可补充类型说明
       位置 : 第52行
       原文 : new HashMap<>(expectedSize / 0.75 + 1)
       说明 : 阿里规约原式为 (int)(expectedSize / 0.75f) + 1，速查版省略
              (int) 强转与 f 后缀，初学者可能产生浮点入参疑虑。
       建议 : 改为 new HashMap<>((int)(expectedSize / 0.75f) + 1)，
              或在括注中注明「int 取整」。

  [P2] 3. 线程池禁用 Executors 的理由可再精简
       位置 : 第58~59行
       原文 : 线程池必须使用 ThreadPoolExecutor 显式构造，禁止 Executors
              工厂方法（避免无界队列导致 OOM）。
       说明 : 理由表述正确，但 Executors.newFixedThreadPool 使用的是
              LinkedBlockingQueue（无界）才致 OOM；newCachedThreadPool
              则是最大线程数 Integer.MAX_VALUE 致 OOM。当前一句话统括
              略有歧义。
       建议 : 可补一句「不同工厂方法风险点不同」，非必须。
