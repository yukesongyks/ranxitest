# 快速排序算法设计文档

## 1. 需求概述

### 1.1 功能需求
实现一个快速排序（QuickSort）算法，能够对整数数组进行升序排序。

### 1.2 非功能需求
- 时间复杂度：平均 O(n log n)，最坏 O(n²)
- 空间复杂度：O(log n)（递归调用栈）
- 稳定性：不稳定排序

---

## 2. 算法设计

### 2.1 核心思想
快速排序采用**分治策略**：
1. **选择基准（pivot）**：从数组中选择一个元素作为基准
2. **分区（partition）**：将数组分为两部分，小于基准的在左边，大于基准的在右边
3. **递归排序**：对左右两部分分别递归执行快速排序

### 2.2 基准选择策略
- **方案A（首元素）**：选择第一个元素作为基准
  - 优点：实现简单
  - 缺点：对已排序数组性能退化到 O(n²)
  
- **方案B（三数取中）**：选择首、中、尾三个元素的中位数作为基准 **[推荐]**
  - 优点：避免最坏情况，性能稳定
  - 缺点：实现稍复杂

### 2.3 分区算法（Lomuto 分区）
```
partition(arr, low, high):
    pivot = arr[high]  // 选择最后一个元素作为基准
    i = low - 1
    for j = low to high - 1:
        if arr[j] <= pivot:
            i++
            swap arr[i] and arr[j]
    swap arr[i + 1] and arr[high]
    return i + 1
```

### 2.4 递归流程
```
quickSort(arr, low, high):
    if low < high:
        pi = partition(arr, low, high)
        quickSort(arr, low, pi - 1)
        quickSort(arr, pi + 1, high)
```

## 3. 接口设计

### 3.1 公开接口
| 方法签名 | 说明 |
|---------|------|
| `void quickSort(int[] arr)` | 对整数数组进行升序排序 |
| `void quickSort(int[] arr, int low, int high)` | 对数组指定范围排序 |

### 3.2 内部方法
| 方法签名 | 说明 |
|---------|------|
| `int partition(int[] arr, int low, int high)` | 分区操作，返回基准最终位置 |
| `void swap(int[] arr, int i, int j)` | 交换数组中两个元素 |

## 6. 风险与应对

| 风险 | 影响 | 应对措施 |
|-----|------|---------|
| 递归深度过大导致栈溢出 | 程序崩溃 | 对小数组切换插入排序，或使用尾递归优化 |
| 最坏情况性能退化 | 性能下降 | 采用三数取中策略选择基准 |
| 大量重复元素性能下降 | 性能下降 | 采用三路快排（荷兰国旗问题） |
