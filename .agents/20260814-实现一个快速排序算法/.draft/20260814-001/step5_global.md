# Step 5 全局约定

## 错误码格式
本模块为纯工具类，不涉及业务错误码。异常处理通过标准 Java 异常（`IllegalArgumentException`）抛出。

## 通用出参结构
本模块为静态方法，无统一出参结构。返回值约定：
- `void` 类型方法：原地修改数组
- 异常场景：抛出 `IllegalArgumentException`，含描述性消息
